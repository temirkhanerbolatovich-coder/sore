## 6. Решения и отклонения

Все решения записаны в `docs/DECISIONS.md` (раздел «Задание №3»). Главное:
- `sharp` перенесён в `dependencies`, добавлен `exceljs@4.4.0`, оба обоснованы.
- Рамка, снимок полки и артикул читаются анонимно (как остальные поля товара); запись только владельцу.
- Импорт идёт через Route Handler, кэш витрины сбрасывается `revalidateTag(…, { expire: 0 })`.
- Подставить текст заказа в личный чат Telegram ссылкой нельзя: текст копируется в буфер обмена.
- Отклонение от задания: количество из прайса не хранится (нет поля), только «в наличии / нет».

## 7. Ограничения и риски

- **Живой ИИ не проверялся.** Качество рамок и названий на реальных снимках неизвестно; бесплатные модели из цепочки (Gemini, OpenRouter) могут отвечать хуже или без точных рамок.
- **Осиротевшие файлы.** Если продавец закрыл вкладку между «ИИ нашёл» и «Опубликовать», вырезки остаются в Storage (в отмене и публикации они убираются, в закрытии вкладки нет). Уборки Storage по расписанию нет, это уже было известным ограничением (`README`).
- **Нагрузка импорта.** Функция БД обрабатывает строки по одной внутри транзакции: 2000 строк, ожидаемо секунды; на облачной базе не мерили.
- **Тарифный лимит 15 товаров** ограничивает и импорт: прайс на тысячи позиций упрётся в него (решение за владельцем продукта).
- **Реальные телефоны и печать** не проверялись; Telegram-ссылка и буфер обмена проверены в Chromium.
- **Ссылки на старое имя** (`dukenai.vercel.app`, `sore.kz`) остаются до выбора домена.

## 9. Как проверить вручную за 10 минут

1. `npx supabase start -x studio,edge-runtime,logflare,vector,realtime,imgproxy,supavisor`, `npm run dev` (или `npm run build && npm start`), открыть `http://localhost:3000` (на этой машине 3000 занят Grafana, используйте `-p 3100`).
2. Войти: `/login` → email `demo@sore.kz`, письмо в `http://127.0.0.1:54324` (локальная почта).
3. Кабинет → «Фото полки»: загрузить любое фото. Без ключа ИИ получите понятную ошибку 503; с ключом: черновики, рамки, выбор, публикация.
4. «Прайс из Excel»: скачать шаблон, добавить строки (одну с пустой ценой), загрузить: итог и отчёт об ошибках; загрузить ещё раз: товары обновились, а не задвоились.
5. «Магазин» → поле «Telegram для покупателей» → `@ник`.
6. Открыть витрину `/<slug>`, добавить товар, оформить заказ: на экране после заказа обе кнопки, Telegram копирует текст заказа.
7. Переключить тему кнопкой в шапке и пройти те же экраны.

## 10. Куда смотреть ревьюеру в первую очередь

1. `supabase/migrations/0018_import_products.sql`: `security invoker` и блок `exception when others` на каждой строке (скрывает причину любой ошибки как `invalid`); для бота нужна сервисная версия (`BOT_CONTRACT.md`, раздел 5).
2. `src/lib/zip-guard.ts`: ручной разбор zip; проверено тестом «врущий заголовок», но реальных xlsx из разных версий Excel и LibreOffice мало.
3. `src/app/dashboard/products/shelf/actions.ts` и `/api/ai/shelf`: уборка файлов и квота ИИ в крайних случаях (двойной клик, обрыв связи).
4. `parsePrice`: правило «`1,500` = 1500» может ошибиться для цены 1,5 ₸ (на практике такой цены нет).
5. Живой ИИ: промпт `buildShelfPrompt` и разбор `parseShelf` написаны под ожидаемый формат ответа, не под фактический ответ конкретной модели.
