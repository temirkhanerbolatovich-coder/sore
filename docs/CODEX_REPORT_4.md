## 6. Решения и отклонения

Подробности — `docs/DECISIONS.md` и `docs/DESIGN_SYSTEM.md`. Новых зависимостей нет. Шаг 2 размещён на пустом кабинете, сохранив прежний redirect создания магазина. Указаны причины длительности наполнения вместо вымышленных минут. Перемещение использует последовательные вызовы существующего moveProduct; при сетевом сбое возможен частичный перенос, о чём интерфейс сообщает и обновляет фактический порядок. Выборка/поиск отключают drag, кнопки меняют общий порядок.

В полном PR присутствуют изменения прежней работы Task 4 (включая документацию и бренд). Их нельзя приписывать текущему выполнению Task 5.
