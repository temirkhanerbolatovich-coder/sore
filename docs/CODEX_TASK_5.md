## 4. Чему мы уже научились (не наступай на те же грабли)

- **Перед e2e всегда `npx supabase db reset`**, затем `npm run build` и `npx playwright test`. E2E идёт на production-сборке (`npm run start`), без пересборки видишь старый код.
- **Не добавляй `loading.tsx` в `src/app/[slug]/`:** потоковая загрузка отдаёт статус 200 вместо 404 для несуществующих магазинов, падают `storefront-status` и `storefront-cache`.
- У `create_order` лимит 10 заказов в час на номер: в тестах каждому заказу давай свой номер.
- Пока на странице виден скелет `loading.tsx`, у него тот же `#main-content`: в тестах на клавиатуру сначала жди реальный заголовок и `waitForLoadState("networkidle")`.
- `seo.spec` иногда падает сразу после `db reset` из-за кеша sitemap; отдельно проходит. Если упал только он, запусти его отдельно и отметь в отчёте.
- `getByAltText` и подобные селекторы в тестах чувствительны к дублям: не повторяй `alt` фото во вторых элементах (в окне просмотра у картинки `alt=""`).
- Кнопка «Товар» в кабинете теперь липкая и скрыта на пустом списке (там «Добавить товар вручную»). Тесты не должны искать её на пустом кабинете.
- Окружение Windows: пути с кириллицей длинные, `git config core.longpaths true` уже включён; в bash-скриптах с многострочным Python сложные кавычки ломаются, пиши скрипты в файл.
