# Пилот: «Повар на выезд · Астана»

Первый живой клиент. Повар с опытом 25+ лет, работает по Астане: выезд на дом и мероприятия (15 000–50 000 ₸, банкет от 50 000 ₸), торты, пироги, выпечка, полуфабрикаты. Заказы приходят время от времени, в основном через Instagram и WhatsApp. Повар дал согласие на пилот; настоящие фото пока только в Instagram.

## Что нужно было доработать в продукте

У повара продаётся прежде всего услуга, а не товар с точной ценой. Добавлен режим цены у любой позиции:

| Режим | Как выглядит | Покупатель |
| --- | --- | --- |
| Точная | `12 000 ₸` | кладёт в корзину и оформляет заказ |
| От | `от 15 000 ₸` | кнопка «Узнать цену» открывает WhatsApp с готовым сообщением |
| По запросу | `Цена по запросу` | то же |

Позиции «от» и «по запросу» нельзя положить в корзину ни через интерфейс, ни прямым запросом к базе (`create_order` отвечает `items unavailable`). Нажатие «Узнать цену» считается обращением и попадает в статистику «Нажали «Заказать»». Миграция: `supabase/migrations/0009_price_modes.sql`.

## Как создать пилотный магазин

Нужна папка с исходными фото. Скрипт обрезает скриншоты Instagram до самого фото, сжимает до 1200 px, загружает в Storage, просит ИИ составить карточки и создаёт магазин (12 позиций выпечки и 3 услуги).

```bash
# локально (по умолчанию WhatsApp магазина = заглушка, чтобы тестовые заказы не уходили повару)
npm run seed:pilot -- --photos путь/к/папке

# с настоящим номером повара (только когда готовы принимать реальные обращения)
PILOT_WHATSAPP=77XXXXXXXXX npm run seed:pilot -- --photos путь/к/папке
```

Переменные: `PILOT_WHATSAPP`, `PILOT_EMAIL` (владелец, по умолчанию `povar@duken.ai`), `PILOT_SLUG` (по умолчанию `povar-astana`). Без `--allow-remote` скрипт работает только с локальной базой. Скрипт можно запускать повторно: товары и файлы магазина пересоздаются.

Фото повара и его номер в репозиторий не попадают.

## Что остаётся сделать с поваром

- [ ] **Цены.** На всю выпечку сейчас «по запросу»: настоящих цен нет, выдумывать их нельзя. Когда повар назовёт цены, он (или вы) меняет режим на «Точная» в кабинете: тогда эти позиции пойдут в корзину.
- [ ] **Оригиналы фото.** Сейчас фото из скриншотов Instagram, качество среднее. Попросить повара прислать исходники.
- [ ] **Реальный номер WhatsApp** (`PILOT_WHATSAPP`) и вход повара в кабинет по его email.
- [ ] **Ссылка в Instagram.** Поставить `duken.ai/povar-astana` в био и закреплённый пост.
- [ ] **Проверить тексты.** Казахские описания составил ИИ: показать кому-то, кто знает язык.
- [ ] **Полуфабрикаты и вторая половина выпечки** (манты, пельмени, чебуреки, сырники и т.д.). На бесплатном тарифе лимит 15 позиций, сейчас занято все 15. Либо убрать часть, либо ждать тариф Pro.
- [ ] **Через 2 недели.** Собрать цифры: просмотры, обращения, заказы и отзыв повара. Это материал для питча.
