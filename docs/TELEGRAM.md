# Telegram-бот SÖRE

Бот делает три вещи:
1. **Продавцу** присылает сообщение о каждом новом заказе (состав, сумма, клиент, дата, кнопки «Открыть заказы», «Написать клиенту в WhatsApp», «✅ Выполнен» и «✖️ Отменить»).
2. **Продавцу** даёт второй вход в магазин рядом с веб-кабинетом (раздел «Бот продавца» ниже).
3. **Владельцу сервиса** присылает сообщение об ошибках на сайте (серверных и в браузере).

## Бот продавца

| В чате | Что происходит |
| --- | --- |
| `/start КОД` | привязка чата к магазину (ссылка из кабинета «Магазин» → «Подключить Telegram») |
| `/start` | логотип (надпись SÖRE) и приветствие на русском и казахском; если чат привязан, витрина и QR-код |
| фото полки | ИИ находит до 12 товаров, вырезает фото каждого, пишет карточки RU/KZ. Сообщение прогресса (✅/⏳), затем список с кнопками «✅ 1», «⬜️ 2»… «📤 Опубликовать», «✖️ Отмена» |
| документ `.xlsx` / `.csv` | импорт прайса той же функцией, что в кабинете; итог текстом, строки с ошибками файлом |
| `/shop` | QR-код витрины картинкой, кнопки «Открыть витрину», «Войти в кабинет» (или «Кабинет» без `BOT_LOGIN_SECRET`), «QR-плакат» |
| `/login` | одноразовая ссылка входа в кабинет без почты: 5 минут, один раз, не больше 10 в час на чат |
| `/orders` | последние 5 заказов со статусами и кнопками «выполнен» / «отменить» |
| `/import` | правила и шаблон прайса `.xlsx` |
| `/help`, `/stop` | справка; отключение бота и уведомлений |

Код: `src/lib/bot/` (бот на grammY в `sore-bot.ts`, логика в соседних модулях), вебхук `src/app/api/telegram/webhook/route.ts`, таблицы в миграции `0019_telegram_bot.sql`.

Правила, общие с кабинетом: квота ИИ (`reserveAi`), лимит 15 товаров бесплатного тарифа (триггер в базе), 20 импортов в час на магазин, фото до 5 МБ, прайс до 4 МБ. Магазин определяется только по привязке `shop_telegram.chat_id`; бот работает только в личных чатах, не чаще 30 апдейтов в минуту на чат. Повторная доставка апдейта отсекается таблицей `bot_updates`. Черновики фото полки живут в `bot_drafts` сутки.

Цены: если ИИ прочитал цену на ценнике, товар публикуется с ней и пометкой «проверить цену», иначе «по запросу». Поменять цену можно в кабинете.

### Логотип

Логотип только у бота, сайт его не использует: надпись SÖRE в стиле направления 05 «Связь» (жирный гротеск, белая надпись на тёмном фоне). Источник `src/lib/brand.ts`, файл `public/brand/sore-bot-avatar.png` 640×640 (`npm run brand:export`). Бот присылает его в приветствии `/start`; аватар ставится вручную: @BotFather → `/setuserpic` → выбрать бота → прислать этот PNG.

### Локальная проверка без публичного адреса

```bash
npm run bot
```

Long polling с теми же модулями. Polling снимает webhook у токена, поэтому используйте отдельного тестового бота от @BotFather, а для боевого после проверки снова выполните `npm run telegram:setup`.

Пока бот не настроен, этих функций в интерфейсе нет: карточка «Заказы в Telegram» в настройках магазина не показывается.

## Как это работает

```
покупатель оформляет заказ → create_order → триггер в базе (pg_net) → POST /api/telegram/notify (секрет)
→ сервер берёт заказ и чат продавца → Telegram Bot API sendMessage
```

В запросе от базы только id заказа; данные клиента сервер читает сам. Привязка: продавец в «Магазин» нажимает «Подключить Telegram», получает ссылку `t.me/<бот>?start=<код>`, нажимает Start, webhook (`/api/telegram/webhook`) сохраняет чат. `/stop` в боте отключает уведомления.

## Настройка (один раз)

1. В Telegram откройте [@BotFather](https://t.me/BotFather), команда `/newbot`, придумайте имя и адрес бота (должен заканчиваться на `bot`). BotFather выдаст **токен**. Не публикуйте его и не присылайте в чаты.
2. Узнайте свой chat id для сообщений об ошибках: напишите боту любое сообщение, затем откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":ЧИСЛО`.
3. Задайте переменные в Vercel (Project → Settings → Environment Variables, окружение Production) или командой `npx vercel env add ИМЯ production`:

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_BOT_USERNAME` | адрес бота без `@` |
| `TELEGRAM_WEBHOOK_SECRET` | любая длинная случайная строка |
| `TELEGRAM_NOTIFY_SECRET` | другая длинная случайная строка |
| `BOT_LOGIN_SECRET` | третья длинная случайная строка (от 32 символов), включает вход в кабинет из бота; необязательно |
| `ADMIN_TELEGRAM_CHAT_ID` | ваш chat id (для ошибок), необязательно |

4. Перевыкатите сайт, затем выполните один раз (с теми же переменными в `.env.local`):

```bash
npm run telegram:setup
```

Скрипт проверит токен, зарегистрирует webhook (сообщения и нажатия кнопок), поставит меню команд и имя SÖRE и сохранит в базе адрес и секрет уведомлений. После обновления бота запустите его ещё раз: старый webhook не получал нажатия кнопок. После этого в «Магазин» появится кнопка «Подключить Telegram».

## Проверка

- Подключите свой чат, оформите тестовый заказ на своём магазине: сообщение должно прийти за несколько секунд.
- Тесты не требуют настоящего Telegram: `tests/e2e/telegram-mock.ts` подменяет Bot API.

## Ограничения

- Webhook Telegram работает только по https и на публичном адресе, локально без туннеля не проверить.
- Если сообщение не доставилось, заказ всё равно сохранён и виден в кабинете: сбой уведомления не мешает заказу.
