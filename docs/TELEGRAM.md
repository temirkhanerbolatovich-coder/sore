# Telegram-бот: уведомления о заказах и об ошибках

Бот делает две вещи:
1. **Продавцу** присылает сообщение о каждом новом заказе (состав, сумма, клиент, дата, кнопки «Открыть заказы» и «Написать клиенту в WhatsApp»).
2. **Владельцу сервиса** присылает сообщение об ошибках на сайте (серверных и в браузере).

Пока бот не настроен, этих функций в интерфейсе нет: карточка «Заказы в Telegram» в настройках магазина не показывается.

## Как это работает

```
покупатель оформляет заказ → create_order → триггер в базе (pg_net) → POST /api/telegram/notify (секрет)
→ сервер берёт заказ и чат продавца → Telegram Bot API sendMessage
```

В запросе от базы только id заказа; данные клиента сервер читает сам. Привязка: продавец в «Магазин» нажимает «Подключить Telegram», получает ссылку `t.me/<бот>?start=<код>`, нажимает Start, webhook (`/api/telegram/webhook`) сохраняет чат. `/stop` в боте отключает уведомления.

## Настройка (один раз)

1. В Telegram откройте [@BotFather](https://t.me/BotFather), команда `/newbot`, придумайте имя и адрес бота (должен заканчиваться на `bot`). BotFather выдаст **токен**. Не публикуйте его и не присылайте в чаты.
2. Узнайте свой chat id для сообщений об ошибках: напишите боту любое сообщение, затем откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":ЧИСЛО`.
3. Задайте переменные в Vercel (Project → Settings → Environment Variables, окружение Production) или командой `npx vercel env add ИМЯ production`:

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `TELEGRAM_BOT_USERNAME` | адрес бота без `@` |
| `TELEGRAM_WEBHOOK_SECRET` | любая длинная случайная строка |
| `TELEGRAM_NOTIFY_SECRET` | другая длинная случайная строка |
| `ADMIN_TELEGRAM_CHAT_ID` | ваш chat id (для ошибок), необязательно |

4. Перевыкатите сайт, затем выполните один раз (с теми же переменными в `.env.local`):

```bash
npm run telegram:setup
```

Скрипт проверит токен, зарегистрирует webhook и сохранит в базе адрес и секрет уведомлений. После этого в «Магазин» появится кнопка «Подключить Telegram».

## Проверка

- Подключите свой чат, оформите тестовый заказ на своём магазине: сообщение должно прийти за несколько секунд.
- Тесты не требуют настоящего Telegram: `tests/e2e/telegram-mock.ts` подменяет Bot API.

## Ограничения

- Webhook Telegram работает только по https и на публичном адресе, локально без туннеля не проверить.
- Если сообщение не доставилось, заказ всё равно сохранён и виден в кабинете: сбой уведомления не мешает заказу.
