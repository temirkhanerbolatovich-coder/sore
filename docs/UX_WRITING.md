# Тексты интерфейса SÖRE

Для кого пишем: продавец в Казахстане, который ведёт магазин с телефона, и его покупатель. Оба спешат, у обоих может быть слабый интернет.

## Тон

- Коротко и по делу, на «вы». Без жаргона, без восклицаний и шуток в ошибках.
- Говорим, что произошло и что сделать дальше. Не виним пользователя.
- Не обещаем того, чего нет: оплаты в приложении и бота для продавца пока нет.
- Названия бренда: **SÖRE** (в заголовках и письмах), в казахском тексте с дефисом: «SÖRE-ге кіру».

## Словарь

| Говорим | Не говорим |
| --- | --- |
| магазин (у продавца), витрина (то, что видит покупатель) | сайт, страница магазина, каталог |
| товар, карточка товара | позиция, лот, продукт |
| прайс (файл Excel или CSV) | таблица, база |
| заказ, статус заказа | покупка, транзакция |
| кабинет | админка, панель управления |
| фото полки | скан, снимок витрины |

## Кнопки

Кнопка начинается с глагола и называет результат.

| Хорошо | Плохо |
| --- | --- |
| Добавить по фото полки | Загрузить |
| Заказать в WhatsApp | Отправить |
| Сохранить настройки | Сохранить |
| Скопировать ссылку | Копировать (если не ясно, что именно) |
| Вернуть (после удаления из корзины) | Отмена |

## Сообщения

- **Ошибка поля:** рядом с полем, с примером. Хорошо: «Укажите телефон, например +7 701 123 45 67». Плохо: «Неверный формат».
- **Ошибка экрана:** что случилось и повтор. Хорошо: «Не удалось загрузить кабинет. Проверьте соединение и повторите попытку». Плохо: «Ошибка 500».
- **Пусто:** почему пусто и что делать. «Пока нет заказов. Отправьте ссылку на магазин клиентам».
- **Подтверждение:** краткое, в прошедшем времени: «Настройки сохранены», «Товар убран из корзины».
- Ошибку сети не выдаём за пустой список.

## Числа и склонения

- Счётные слова склоняем только через `plural()` из `src/lib/plural.ts` (1 товар, 2 товара, 5 товаров, 11 товаров, 21 товар).
- Цены: `formatPrice()`, неразрывный пробел перед знаком тенге: «4 000 ₸».
- Телефон: `+7 701 123 45 67`.

## Казахский

- На витрине и в корзине вся видимая лексика должна быть на казахском; название товара и магазина остаются как ввёл продавец.
- Одни и те же термины переводим одинаково: заказ — «тапсырыс», корзина — «себет», магазин — «дүкен», сатушы — продавец.
- Новые казахские строки добавляем рядом с русскими в `src/lib/lang.ts` и показываем носителю языка. Не выдумываем грамматику: сомневаешься, помечай строку комментарием `// проверить носителем`.
